# 천하제일 손가락 대회

Next.js App Router로 만든 브라우저 리듬게임입니다. 혼자하기와 방번호로 참여하는 함께하기를 지원합니다.

## 실행

Node.js 20.9 이상에서 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다. 배포용 빌드는 `npm run build`, 빌드된 서버는 `npm start`로 실행합니다. 규칙과 방 동작 테스트는 `npm test`로 확인합니다.

## 게임

- EASY·NORMAL은 **S D J K** 4레인, HARD·SUPER HARD는 **S D F 스페이스바 H J K** 7레인입니다.
- 게임 속도는 1.00×부터 2.00×까지 선택합니다. 음악 재생 속도는 그대로이고 노트가 내려오는 속도만 바뀝니다.
- 긴 노트는 끝까지 누릅니다. PERFECT, GREAT, GOOD, MISS 판정과 콤보, 정확도, 점수를 보여줍니다.
- 혼자하기와 함께하기의 완료 기록은 난이도별 전체 랭킹에 저장됩니다. 모든 플레이어가 같은 순위를 보고, 화면의 랭킹은 15초마다 새로고침됩니다.
- 함께하기에서는 방장이 설정과 시작을 담당합니다. 참가자 점수와 진행 상황을 같은 방에서 실시간으로 공유합니다. 모두 끝나면 방장은 참가자와 방번호를 유지한 채 다음 판을 시작할 수 있습니다.
- 방번호를 직접 입력하거나 오른쪽의 **현재 대기 중인 방** 목록을 눌러 참가할 수 있습니다. 목록에는 게임을 시작하지 않았고 빈자리가 있는 방만 표시됩니다.

## 구성

- `app/`: Next.js 페이지, 클라이언트 게임 진입점, 방 API Route Handlers
- `src/`: 게임 엔진, 채보, 판정 규칙, 화면 스타일
- `rooms.js`: 방 상태와 참가자 관리

## Vercel에서 함께하기 설정

Vercel Marketplace에서 Upstash Redis를 프로젝트에 연결하고 다음 환경 변수가 등록됐는지 확인한 뒤 다시 배포합니다.

```text
UPSTASH_REDIS_REST_URL
UPSTASH_REDIS_REST_TOKEN
```

기존 Vercel KV 연결의 `KV_REST_API_URL`, `KV_REST_API_TOKEN`도 사용할 수 있습니다. 서버에서 방 정보를 Redis에 저장하므로 여러 Vercel 함수 인스턴스가 같은 방에 접근합니다. 참가자 화면은 약 0.7초마다 방 상태를 갱신합니다. Redis 연결 정보가 없는 Vercel 배포에서는 함께하기 시작 시 설정 오류를 표시합니다. 로컬 개발에서는 연결 정보가 없으면 메모리 저장소를 사용합니다.

전체 랭킹도 같은 Redis에 저장됩니다. 화면에는 해당 난이도의 상위 기록 5개를, 게임 결과에는 상위 기록과 내 순위를 보여줍니다. Redis 연결 전 브라우저에 저장된 혼자하기 기록은 자동 이전되지 않습니다.

방은 시간 제한 없이 유지되며 마지막 참가자가 나가면 삭제됩니다. Redis를 연결하기 전에 만든 방은 새 저장소로 옮겨지지 않으므로 새 방을 만들어야 합니다.
