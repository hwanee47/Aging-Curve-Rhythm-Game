#. 에이징커브 테스트

Next.js App Router로 만든 브라우저 리듬게임입니다. 혼자하기와 방번호로 참여하는 함께하기를 지원합니다.

## 실행

Node.js 20.9 이상에서 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다. 배포용 빌드는 `npm run build`, 빌드된 서버는 `npm start`로 실행합니다. 규칙과 방 동작 테스트는 `npm test`로 확인합니다.

## 게임

- EASY·NORMAL은 **S D J K** 4레인, HARD·SUPER HARD는 **S D F 스페이스바 H J K** 7레인입니다.
- 게임 속도는 1.00×부터 2.00×까지 선택합니다. 음악 재생 속도는 그대로이고 노트가 내려오는 속도만 바뀝니다.
- 긴 노트는 끝까지 누릅니다. PERFECT, GREAT, GOOD, MISS 판정과 콤보, 정확도, 점수를 보여줍니다.
- 혼자하기 기록은 난이도별로 현재 브라우저에 저장됩니다.
- 함께하기에서는 방장이 설정과 시작을 담당합니다. 참가자 점수와 진행 상황을 같은 방에서 실시간으로 공유합니다. 모두 끝나면 방장은 참가자와 방번호를 유지한 채 다음 판을 시작할 수 있습니다.

## 구성

- `app/`: Next.js 페이지, 클라이언트 게임 진입점, 방 API Route Handlers
- `src/`: 게임 엔진, 채보, 판정 규칙, 화면 스타일
- `rooms.js`: 방 상태와 참가자 관리

현재 방 상태는 **실행 중인 Node.js 프로세스의 메모리**에 있습니다. 로컬 또는 단일 서버에서는 함께하기가 동작합니다. Vercel처럼 요청이 여러 함수 인스턴스에 분산되는 환경에서 함께하기를 운영하려면 공유 저장소와 실시간 전송 계층으로 방 상태를 옮겨야 합니다. Next.js 전환만으로 메모리 공유가 보장되지는 않습니다.
